# 🧼 Laundry & Home Services Booking Web App

An interactive, responsive single-page web application designed with a **macOS Web Book Window** aesthetic. Users can browse home and laundry services (Dry Cleaning, Wash & Fold, Leather Cleaning, Sofa Cleaning), skip or add services to their cart dynamically, calculate live totals, and place service bookings seamlessly.

---

## ✨ Features

- 🧺 **Dynamic Service Carousel**:
  - **Dry Cleaning** — ₹200
  - **Wash & Fold** — ₹150
  - **Leather & Suede Cleaning** — ₹999
  - **Sofa & Upholstery Cleaning** — ₹799
- 🛒 **Interactive Cart & Real-Time Calculation**: Add or skip items with instant update of total amount, serial numbering, and single-click item removal.
- 📋 **Integrated Booking Form**: Built-in validation with modal confirmation upon successful order placement.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile views.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic document structure
- **CSS3**: Modern layout, glassmorphism backdrop blur, custom styling
- **JavaScript (ES6+)**: Dynamic DOM manipulation, state management for cart and carousel

---

## 🚀 How to Run

1. Make sure `index.html`, `style.css`, and `script.js` are saved in the **same folder**.
2. Double-click **`index.html`** to open it in any web browser (Chrome, Firefox, Edge, etc.).

---

*Alternatively, if you use Visual Studio Code, right-click `index.html` and select **Open with Live Server**.*
